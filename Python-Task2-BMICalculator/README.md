# BMI Calculator

## Project Description

This project is a beginner-friendly BMI (Body Mass Index) Calculator developed using Python. It takes the user's weight in kilograms and height in meters through the command line, calculates the BMI, and classifies the result into standard BMI categories.

## Features

* Accepts weight in kilograms.

* Accepts height in meters.

* Calculates BMI using the formula:

  `BMI = weight / (height²)`

* Classifies BMI into:

  * Underweight: BMI < 18.5
  * Normal: BMI 18.5–24.9
  * Overweight: BMI 25–29.9
  * Obese: BMI ≥ 30

* Displays BMI rounded to 2 decimal places.

* Validates user input.

* Rejects non-numeric and non-positive values with helpful error messages.

## Technologies Used

* Python
* Command Line Interface

## How to Run

1. Make sure Python is installed.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

```bash
python BMI_Calculator.py
```

4. Enter your weight in kilograms.
5. Enter your height in meters.
6. The program displays your BMI and corresponding category.

## Example

```text
Welcome to the BMI Calculator
Enter your weight in kilograms: 75
Enter your height in meters: 1.70

Your BMI is: 25.95
You are classified as: Overweight
```
