# Voice Assistant

A Python-based voice assistant that listens to spoken commands and responds using text-to-speech.

## Features

- Captures voice input using a microphone
- Responds to greetings
- Provides text-to-speech responses
- Handles voice recognition errors
- Tells the current time
- Tells the current date
- performs a websearch based on voice input

## Technologies Used

- Python
- SpeechRecognition
- pyttsx3
- PyAudio
- datetime
- webbrowser

## How to Run

1. Install the required libraries:

pip install SpeechRecognition pyttsx3 PyAudio

2. Run the program:

python voice_assistant.py
